Welcome to my development repository. Here, I collect the projects and practical assignments developed for the Web Application Development course.

Repository Contents

Practice 3: Online Store (PHP - MVC)
A complete web system built with the Model-View-Controller architecture, focused on managing an e-commerce platform.

Technologies: PHP, MySQL, CSS, JavaScript.

Main Structure:

controlador/: Business logic and action management (users, products, orders, etc.).

modelo/: Database connection.

img/: Graphic assets and product catalog.

Root files: index.php, login.php, productos.php, etc.

Database: Includes the SQL script to set up the store database structure.

Practice 2: Java Project (Maven)
A desktop and backend application developed in Java using the standard Maven dependency management structure.

Technologies: Java, Maven.

Main Structure:

src/: Source code of the application.

target/: Compiled build files.

practica2.jar: Project executable.

Supporting SQL script.
